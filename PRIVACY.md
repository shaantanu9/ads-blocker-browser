# Privacy promise

Open Adblock Browser has no account, analytics, advertising SDK, affiliate programme or project-operated browsing
server. Page requests go directly from the device to the site the person chooses to open.

History, cookies/site storage, cache, downloads, permissions, bookmarks and blocker exceptions are local to the device
and will be individually clearable. Optional filter updates fetch only signed rules over HTTPS; the project must not
receive visited URLs, page text, block events, history or a persistent user identifier.

Broken-site reports must be shown to the person before sending. Their default contents exclude credentials, page text,
query strings and identifying values.
